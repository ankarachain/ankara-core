# Ankara Chain SDK

**Ankara Chain** is open-source infrastructure for tokenizing real-world assets (RWAs) on-chain. Think of it as the Stripe for RWA tokenization in Africa — plug it into your existing app the same way you'd plug in a payments library, and keep full control of your business logic.

## Architecture

Ankara Chain sits between raw blockchain protocols and your product. You own the business layer — we provide the contract infrastructure.

```
┌─────────────────────────────────────────┐
│  End Users & Investors                  │  ← Farmers, businesses, diaspora
├─────────────────────────────────────────┤
│  Your Application                       │  ← Business logic, UX, compliance decisions
├─────────────────────────────────────────┤
│  Ankara Chain SDK          ← You are here│  ← Smart contracts, CLI, TypeScript API
├─────────────────────────────────────────┤
│  Blockchain Protocol                    │  ← Ethereum · Polygon · Stellar · Celo · BNB
└─────────────────────────────────────────┘
```

## Why Ankara Chain?

<AccordionGroup>
  <Accordion title="Plug in, not lock in">
    Import `@ankarachain/sdk` into your existing Node.js or React app. No platform dependency. Full chain custody stays with you. The contracts are yours — deployed to your chosen network under your deployer key.
  </Accordion>

  <Accordion title="Built for African context">
    Asset schemas for farmland, commodities, and receivables. Identity hooks for BVN, NIN, Huduma Namba, and Ghana Card — not retrofitted from European standards. Supported countries: Nigeria, Ghana, Kenya, South Africa.
  </Accordion>

  <Accordion title="Compliance hooks, not compliance">
    Ankara Chain provides the `IIdentityVerifier` interface. You plug in your KYC provider — Smile Identity, Persona, or custom — without redeploying core contracts.
  </Accordion>

  <Accordion title="Open core, enterprise layer">
    Smart contracts and SDK core are MIT licensed. Dashboard, regulatory compliance modules, and audit reporting are paid enterprise tiers. Like Terraform, but for RWA.
  </Accordion>
</AccordionGroup>

## SDK Modules

| Module | License | Description |
|--------|---------|-------------|
| **Token Factory** | MIT | Deploy RWA tokens from pre-audited templates |
| **Asset Registry** | MIT | On-chain metadata schema and lifecycle management |
| **Transfer Engine** | MIT | Permissioned transfers, time-locks, escrow |
| **Identity Hooks** | MIT | Pluggable KYC interface (`IIdentityVerifier`) |
| **Multi-Chain Adapter** | MIT | Unified EVM + Stellar API |
| **Enterprise Dashboard** | Paid | Web UI, compliance modules, audit reporting |
