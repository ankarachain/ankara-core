$ npm install @ankarachain/sdk 
import { TokenFactory } from "@ankarachain/sdk";

const factory = new TokenFactory({
  network: "stellar-testnet",
  stellarSecretKey: process.env.STELLAR_SECRET_KEY,
});

// A 10,000 m² parcel in Kano — fractional shares, KYC-gated
const { tokenAddress } = await factory.deployFarmland({
  name: "Kano Farmland Token", symbol: "KFT",
  assetId: "NG-KN-0042", countryCode: "NG",
  metadata: { location: "12.0022, 8.5919", areaSqMeters: 10_000n, /* … */ },
});
// A diaspora build, released stage by stage — not on a phone call
const { escrowAddress } = await factory.deployEscrow({
  payer: amaka, payee: contractor, arbiter: siteProofCo, token: usdc,
  milestones: [{ amount: 2400n }, { amount: 3200n }, { amount: 2400n }],
});

const escrow = new EscrowManager(adapter, escrowAddress);
await escrow.fund(0);              // foundation stage
await escrow.markDelivered(0);     // contractor flags it done
await escrow.approveMilestone(0);  // released after verified photos
// Borrow against a warehouse receipt instead of selling the harvest
const vault = new CollateralVault(adapter, VAULT);

const { loanId } = await vault.openLoan(maizeReceipt, 12_000n, 5_760n);
await vault.currentLtvBps(loanId);   // live, oracle-priced
await vault.repayLoan(loanId);       // collateral comes home

Payments

Diaspora builds, cross-border payouts, salaries and cooperative distributions. The on-chain half is done, so you can spend your time on the relationships.

Explore payments

Milestone escrow

Tranche-based deals with arbiters, disputes and a timelock release if the payer goes silent.

Anchor ramps SEP-24 · SEP-31

Any Stellar anchor, interactive or direct: fiat to a bank or mobile-money wallet with no hosted page.

Streams & vesting new

Per-second salary streams with cliffs, or tranche schedules. Claimable at any time, and cancellable if you allow it.

Batch payouts new

Pay 100 recipients per transaction from a CSV. Each batch is atomic, so a payroll run is never half-paid.

Capital markets

Finance primitives, not just tokens.

Tokenizing an asset is where the product starts. Lend against it, pool it, pay its income out, trade it and insure it, all with Soroban contracts on Stellar.

Explore finance

Collateral & credit new

Borrow against RWAs at an oracle-priced LTV, or against a pluggable credit score with no collateral at all.

Savings circles new

On-chain ajo, esusu and chama: rotating pots or pooled savings-and-credit groups, with the group as guarantor.

Income & liquidity new

Pay rent and royalties pro-rata at a snapshot, and let holders exit through an RFQ market with atomic settlement.

Parametric cover new

Drought, heat or a missed delivery pays holders automatically once the oracle or attestation says so.

Compliance & governance

Compliance hooks, not compliance lock-in.

Ankara provides the interfaces. You plug in your KYC provider, your regulator's rules and your community's votes, without redeploying the assets.

Identity gates

Every mint and transfer checks a pluggable verifier: a whitelist, an attestation registry, or your KYC provider.

Freeze & clawback

An opt-in compliance policy for court orders, fraud and sanctions, with the reason recorded on-chain.

Proof of reserve

Quorum-attested reserves checked against live supply, so "backed 1:1" becomes something anyone can verify.

Community governance

Pool vaults can be run by their holders: share-weighted proposals, timelocks, and no single key in charge.
